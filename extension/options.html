Cussijn Tree View

A treemap of your mailbox, in the style of the old SequoiaView disk-space tool and using the same "cushion treemap" shading technique (van Wijk & van de Wetering, TU Eindhoven) its name winks at - each folder is a rectangle sized by message count (or size), colored by whichever message tag is most common in it. Click the toolbar button (or press Ctrl+Shift+Y, or right-click a folder and choose "Open in Cussijn Tree View") to open it as a tab; click any folder's rectangle to drill into its real contents - by whichever dimension you're grouping by, then by sender.

This extension only ever calls Thunderbird's own messenger.accounts, messenger.messages, and messenger.menus APIs to read message headers/tags and add its one folder-pane context menu entry - it never opens a network connection, never sends anything anywhere, and has no companion process or native host to install. There is nothing else to configure here.
